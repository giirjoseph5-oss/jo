This tool displays historical/backtested statistics and live empirical probabilities only. It does not place or automate trades, and it does not guarantee future results. "NO TRADE" is the default and expected output whenever evidence is insufficient. This version connects through a relay server (see the separate deriv-relay package) instead of Deriv directly, to route around network-level blocking. Note: this build implements a lean core — live tick feed, EMA/RSI/streak evidence, an empirically-updated probability bucket, sample-size gating, and a self-grading signal log — as a functioning first version, not the full historical-model/walk-forward/D'Alembert-simulation/Wilson-CI/multi-window package described. Ask if you'd like any of those layers added next.
